설치 방법 (현장 기기 PC)

  1. 다운로드 — 위 목록에서 최신 ..._Setup.zip 을 내려받습니다.
  2. 압축 풀기 — 내려받은 zip 을 마우스 오른쪽 → 압축 풀기(모두 압축 풀기) 로 풉니다. zip 안을 미리보기 상태에서 바로 실행하면 설치가 실패할 수 있으니, 반드시 풀어서 나온 ..._Setup.exe 를 사용합니다.
  3. 실행 — ..._Setup.exe 를 실행하면 관리자 권한(UAC) 확인 창이 뜹니다. 예 를 누릅니다. “Windows에서 PC를 보호했습니다” 화면이 나오면 추가 정보 → 실행 으로 진행합니다.
  4. 설치 — 기본 경로 C:\LinkTech\LinkTurnAd 에 설치됩니다. 설치 과정에서 코드서명 인증서 신뢰 등록과 부팅 시 자동 실행 등록이 함께 수행됩니다.
  5. 기기 설정 — 설치 후 열리는 제어판 에서 서버 주소와 기기 ID 를 입력해 저장합니다. 관리자에게 받은 간편 설정 코드(4자리) 가 있으면 코드만 입력해도 디바이스 토큰이 자동 설정됩니다(발급 후 30분 이내).
  6. 확인 — 43인치 세로형 모니터(1080×1920)에 광고 화면이 표시되는지 확인합니다. 콘텐츠는 내려받아 캐시된 뒤 재생되므로 최초 실행 직후에는 기본 화면이 잠시 보일 수 있습니다.
제어판을 닫은 뒤 다시 열려면 바탕화면(또는 시작 메뉴)의 링크턴 광고 플레이어 바로가기를 실행하세요. 프로그램을 완전히 종료할 때는 제어판의 프로그램 완전 종료 를 사용합니다(창만 닫으면 자동으로 다시 열립니다).
